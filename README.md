# Go pprof Demo

Учебный эксперимент: как найти CPU bottleneck в Go-сервисе через `net/http/pprof`, исправить его и сравнить результаты.

## Что внутри

- `GET /compute?mode=slow&n=12000` — сборка строки повторной конкатенацией.
- `GET /compute?mode=fast&n=12000` — та же задача через `strings.Builder`.
- CPU profiling через `net/http/pprof`.
- Бенчмарки и тест корректности результата.

Цифры зависят от версии Go и компьютера; универсальных значений здесь нет.

## Запуск

1. Выполнить:

```bash
go test ./...
go test -bench=. -benchmem
go run .
```

Сервис будет доступен на `http://localhost:8080`.

## Снимаем CPU profile

Пока сервис запущен, вызовите endpoint несколько раз во время сбора профиля.

Windows CMD:

```bat
curl.exe "http://localhost:8080/compute?mode=slow&n=12000"
```

Во втором окне CMD запустите сбор профиля на 20 секунд:

```bat
go tool pprof http://localhost:8080/debug/pprof/profile?seconds=20
```

Пока профиль собирается, повторяйте вызов `/compute?mode=slow&n=12000`. Затем в консоли `pprof` выполните:

```text
top
list buildSlow
```

Команда `web` построит граф, если установлен Graphviz:

```text
web
```

Если в профиле мало образцов, повторите сбор с более интенсивной нагрузкой. CPU profile учитывает выполнение, происходившее в интервал профилирования.

## Сравниваем варианты

```bash
go test -bench=. -benchmem
```

Сравните `ns/op`, `B/op` и `allocs/op` у двух бенчмарков. Запускайте несколько раз и не выдавайте результаты одной машины за универсальную цифру.

## Что важно понимать

- `pprof` показывает, куда уходит CPU при конкретной нагрузке; он не доказывает автоматически, что найденная функция — единственная причина медленного API.
- Сначала снимите профиль под репрезентативной нагрузкой, потом меняйте код.
- После оптимизации проверьте корректность и повторите измерения.
- Медленный вариант намеренно неэффективен, поэтому значение `n` ограничено.
- Не открывайте `pprof` наружу без контроля доступа. В production диагностические endpoints обычно размещают на отдельном защищённом listener или ограничивают доступ.

Это демонстрационный проект, не готовая нагрузочная система.
